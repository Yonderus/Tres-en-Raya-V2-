Com jugar

Tu ets la X; la màquina, la O. Alinea tres fitxes teues per guanyar.

▶ Obrir el joc

Passos de la partida

  1. Fase de col·locacióFes clic en una casella buida per posar la teua X. La màquina respondrà amb una O. Cadascú col·loca 3 fitxes.
  2. Fase de movimentQuan tots dos teniu 3 fitxes, ja no se'n col·loquen més. Fes clic en una de les teues X per seleccionar-la i després en una casella buida per moure-la. La màquina mourà una de les seues a l'atzar.
  3. GuanyarAlinea les teues tres X en fila, columna o diagonal. En guanyar o perdre, el tauler es bloqueja i el marcador s'actualitza.
  4. ReiniciarEl botó Reiniciar buida el tauler per a una nova partida, mantenint el marcador acumulat.

Executar-lo en local

No cal instal·lar res ni compilar: és HTML, CSS i JavaScript purs.

git clone https://github.com/Yonderus/Tres-en-Raya-V2-.git
cd Tres-en-Raya-V2-

Després, obri index.html al navegador (doble clic) o, dins VS Code, fes servir l'extensió Live Server per recarregar automàticament a cada canvi.
